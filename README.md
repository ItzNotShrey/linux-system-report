# Linux System Report Generator

## About the Project
The Linux System Report Generator is a Bash scripting project that collects basic information about a Linux system and saves it in a text file.

This project was developed as part of the GIT IT STARTED workshop at Haldia Institute of Technology (HIT Haldia).

## Features

- Displays the system hostname.
- DIsplays the Linux Kernel Version.
- Shows disk usage.
- Shows memory usage.
- Lists the top five CPU-consuming processes.
- Saves the results to system-report.txt.

## Requirements

- system_report.sh: Main Bash script.
- system_report.txt: Generated System Report.
- README.md: Project documentation.

## How to Run

1. Open a termina in the project directory.
2. Make the script executable.
3. Run the script
4. View the generated reports.

## Commands Used
- hostname: Displays the system hostname.
- uname -r: Displays the kernel version.
- df -h: Displays disk usage.
- free -h: Displays memory usage.
- ps: Displays running processes.
- head: LImits the displayed process entries.

## Learning Outcomes
This project demonstrates Bash scripting, Linux commands, file permissions, output redirection, Git version control, and GitHub repository management.
